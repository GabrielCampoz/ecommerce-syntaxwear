# SyntaxWear - Tênis e Sneakers Online

## Descrição do Projeto

O **SyntaxWear** é um projeto de e-commerce focado na venda de tênis e sneakers online. Desenvolvido com HTML e CSS puro, o objetivo é criar uma experiência de usuário intuitiva e visualmente atraente para a compra de calçados modernos e exclusivos. O site apresenta uma estrutura responsiva, garantindo que a navegação seja fluida em diferentes dispositivos.

## Tecnologias Utilizadas

*   **HTML5**: Para a estruturação do conteúdo da página.
*   **CSS3**: Para a estilização e responsividade do layout.

## Estrutura do Projeto

O projeto está organizado da seguinte forma:

```text
ecommerce-syntaxwear/
├── css/
│   ├── components/
│   │   ├── footer.css
│   │   ├── header.css
│   │   ├── hero.css
│   │   ├── product-category.css
│   │   └── product-grid.css
│   ├── base.css
│   ├── layout.css
│   ├── reset.css
│   └── variables.css
├── images/
│   ├── icons/
│   └── logo/
├── index.html
└── README.md
```


*   `css/`: Contém todos os arquivos de estilo do projeto.
    *   `components/`: Estilos específicos para componentes reutilizáveis (cabeçalho, rodapé, hero, categorias de produto, grid de produtos).
    *   `base.css`: Estilos base para elementos HTML.
    *   `layout.css`: Estilos para o layout geral da página.
    *   `reset.css`: Folha de estilo para resetar padrões de navegadores.
    *   `variables.css`: Definição de variáveis CSS para cores e fontes.
*   `images/`: Armazena todas as imagens e ícones utilizados no site.
*   `index.html`: O arquivo principal HTML que estrutura o conteúdo do e-commerce.
*   `README.md`: Este arquivo, com informações sobre o projeto.

## Como Visualizar

Para visualizar o projeto, basta abrir o arquivo `index.html` em qualquer navegador web moderno. Não há necessidade de instalação de dependências ou servidor local, pois é um projeto estático.

1.  Clone o repositório:
    ```bash
    git clone https://github.com/GabrielCampoz/ecommerce-syntaxwear.git
    ```
2.  Navegue até o diretório do projeto:
    ```bash
    cd ecommerce-syntaxwear
    ```
3.  Abra o arquivo `index.html` no seu navegador preferido.

## Funcionalidades

*   **Design Responsivo**: Adapta-se a diferentes tamanhos de tela (desktops, tablets e smartphones).
*   **Navegação Intuitiva**: Menu de navegação claro e fácil de usar.
*   **Seção Hero**: Destaque para produtos ou promoções com chamada para ação.
*   **Categorias de Produtos**: Organização visual de produtos por categorias (Casual, Esporte, Masculino, Feminino, Outlet).
*   **Grid de Produtos**: Exibição de produtos em um formato de grade.
*   **Rodapé Completo**: Informações de contato, links úteis e redes sociais.
